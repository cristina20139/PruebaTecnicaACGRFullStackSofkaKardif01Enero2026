P:1.﻿¿Por qué se eligió Spring WebFlux para el backend y qué beneficio aporta este stack?

R:El backend declara la dependencia org.springframework.boot:spring-boot-starter-webflux en backend/PruebaTecnicaACGRJavaBackend/build.gradle, activando el stack reactivo para atender peticiones concurrentes y evitar bloqueos de hilos como ocurre en Spring MVC, lo que mejora la eficiencia del módulo financiero.

Referencia: backend/PruebaTecnicaACGRJavaBackend/build.gradle

P:2.¿Cómo se refleja la asincronía en los endpoints del controlador?
