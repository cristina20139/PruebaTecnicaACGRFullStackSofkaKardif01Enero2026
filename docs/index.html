📘 Contexto literal

El equipo de banca necesita un módulo que procese transacciones financieras y liquide comisiones basadas en reglas de negocio dinámicas. El candidato debe demostrar su capacidad para manejar flujos asíncronos y persistencia relacional sólida.

⚙️ Requisitos Funcionales

🧠 Backend

Java • Spring WebFlux

Crear un endpoint reactivo (WebFlux) para registrar transacciones.

Implementar un servicio que calcule una comisión del 5% para transacciones > 10,000 y 2% para menores, y persistir ID, Monto, Comisión y Fecha en Oracle (o H2 para la prueba).

🎨 Frontend

Angular

Crear un Dashboard que consuma el API y liste las transacciones en tiempo real.

Implementar un formulario con validaciones reactivas para nuevas transacciones.

🤖 Uso de IA (Opcional)

El candidato puede usar asistentes (Copilot/ChatGPT) para optimizar el código o generar pruebas unitarias. Si lo hace, debe declarar en qué partes la utilizó para la revisión técnica.

✅ Criterios de Aceptación

  • Uso de Clean Code y principios SOLID.
  • Pruebas unitarias con JUnit/Mockito.
  • Manejo de errores global en el API.
